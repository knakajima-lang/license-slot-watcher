# 学科試験 空き枠ウォッチャー（警視庁）

府中・鮫洲・江東の学科試験（教習所卒業者）の空き状況を約10分おきにチェックし、次の2つを LINE に通知します。

- **1月枠の公開**：1月の予約枠が公開されたとき
- **キャンセル枠**：11月・12月・1月で、満席だった日に空きが出たとき

予約は行いません。通知が来たら、リンクから自分で予約してください。
確認には予約サイトの公開カレンダー（誰でも見られる空き状況）だけを使います。個人情報の入力や保存はしません。

---

## セットアップ（20分ほど）

### 1. LINE の通知用アカウントを作る（Messaging API）

1. [LINE Developers](https://developers.line.biz/console/) に LINE アカウントでログインします。
2. 「プロバイダー作成」で名前を付けます（例：自分用）。
3. 「Messaging API チャネル」を作成します。チャネル名は「学科試験通知」など。LINE公式アカウントが一緒に作られます。
4. チャネルの **「Messaging API設定」タブ**で次の2つを行います。
   - QRコードを読み取って、このアカウントを**友だち追加**する
   - 一番下の「チャネルアクセストークン（長期）」で **発行** を押し、表示された文字列を控える
5. **「チャネル基本設定」タブ**の一番下にある **「あなたのユーザーID」**（U から始まる文字列）を控えます。

> 無料プランで月200通まで送れます。通知は1回のチェックにつき最大1通にまとめています。

### 2. GitHub にリポジトリを作る

1. [GitHub](https://github.com/new) で新しいリポジトリを作成します。**Private（非公開）** を選び、名前は `license-slot-watcher` など。
2. 「uploading an existing file」から、このフォルダの中身をすべてアップロードします。
   - `monitor.py`
   - `.github/workflows/watch.yml`（フォルダ構成ごと）
   - `README.md`

> `.github` は隠しフォルダなので、Mac の Finder で表示されない場合は `⌘ + Shift + .` を押してください。

### 3. LINE の情報を GitHub に登録する

リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で、次の2つを登録します。

| Name | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | 手順1-4 で控えたトークン |
| `LINE_USER_ID` | 手順1-5 で控えたユーザーID |

### 4. テスト通知を送る

1. リポジトリの **Actions** タブを開き、ワークフローを有効にします（確認が出た場合）。
2. 左の「学科試験 空き枠ウォッチ」→ **Run workflow** →「テスト通知を送る」にチェックしたまま実行します。
3. LINE に「【テスト】空き枠ウォッチャーは動いています」と、試験場・月ごとの空き状況が届けば完了です。以降は自動で約10分おきにチェックします。

**テストでエラーになったとき**：Actions の実行ログに `403` や `timed out` が出ている場合、予約サイトが GitHub のサーバー（海外）からのアクセスを受け付けていない可能性があります。その場合は自分のPCで動かす方式に切り替えますので、相談してください。

## 設定を変えたいとき（任意）

**Settings → Secrets and variables → Actions → Variables** で、次の値を上書きできます。

| Name | 既定値 | 説明 |
|---|---|---|
| `PLACE_CODES` | `270,280,250` | 270=府中、280=鮫洲、250=江東。府中だけにしたい場合は `270` |
| `MONTHS` | `202611,202612,202701` | 見張る月 |
| `COURSE_CODE` | `11` | 予約画面でマイナ免許証を選んだ場合は `61` |

## 止めたいとき

予約が取れたら、Actions →「学科試験 空き枠ウォッチ」→ 右上「…」→ **Disable workflow** で止めてください。

## 注意

- GitHub の定期実行は、混雑時に数分〜十数分遅れることがあります。
- 空きが出ても、通知を見た時点で埋まっていることがあります（早い者勝ちです）。
- サイトに負担をかけないよう、チェック間隔は10分より短くしないでください（利用規約 第8条8号「運営を不当に妨害する行為」への配慮）。
- 予約は1人1件です。取り直す場合は、先に今の予約をキャンセルしてください。
